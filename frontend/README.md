# TEAM 꺼드럭's 의정이슈레이더 (고대비 밝은 테마 단일화)

본 프로젝트는 17개 시·도의회 정책 시공간 확산 및 미래 예측 인텔리전스 대시보드입니다.
공무원, 관리자 및 평가위원분들의 가독성에 최적화된 **고대비 밝은 테마(Light Theme)** 단일 체제로 구성되어 있습니다.

---


## [주요 특징]

1. **시니어·공무원 친화적 고대비 밝은 테마**:
   - 배경: 소프트 슬레이트 (`#f1f5f9`), 카드: 순백색 (`#ffffff`), 텍스트: 딥 네이비 (`#0f172a`)
   - 기본 글자 크기 17px 확대 및 상단 3단계 조절 옵션 (`작게 15px / 보통 17px / 크게 19.5px`) 제공
2. **지도 중심 인터랙션 (Map-Driven Detail)**:
   - 대한민국 지도 상의 의회 마커 클릭 시 해당 의회의 **최초 관측 순서, 시차(+일), 발언 빈도수(건), 원문 회의록 발췌** 상세 화면 즉시 연동
3. **단순화된 3대 핵심 탭**:
   - `메인 검색/분석 대시보드`: 시공간 확산 맵 + 시차 상세 + 차기 예측 통합 뷰
   - `10대 대표 키워드/이슈 (TOP 10)`: 전국 단위 대표 이슈 및 모델 지표
   - `근거 원문 상세 내용`: 시·도의회 원문 발언 근거 검색 및 필터링
4. **채널톡 스타일 플로팅 미니 AI 챗봇**:
   - 우측 하단 플로팅 아이콘을 통해 화면 공간 낭비 없이 대화형 정책 질의응답 지원
