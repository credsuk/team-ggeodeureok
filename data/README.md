# data/ — 회의록 데이터와 검색용 산출물

현재 폴더에는 지방의회 회의록 원본 및 전처리 산출물, ChromaDB·SQLite 검색 인덱스와 분석 캐시가 있습니다. 데이터 본문과 대용량 생성 파일은 Git에 올리지 않도록 설정되어 있고, 이 안내 파일만 저장소에 포함됩니다.

## 제출 전에 할 일

- 대회에서 제공·허용한 데이터만 사용하고, 데이터 출처·버전·이용 조건을 기록하세요.
- 참가자에게 제공해야 하는 입력 파일은 대회 요구 범위와 라이선스를 확인한 후 별도 패키지로 준비하세요. 현재 로컬 `data/` 전체를 그대로 공개·업로드하지 마세요.
- 데이터의 기간, 의회 범위, 전처리 여부와 실제 포함 파일을 확인해 결과 보고서에 명시하세요. 이 저장소가 2024·2025년 자료를 포함한다고 해서 전체 범위가 완전하다고 단정하지 마세요.
- 대용량 원본·인덱스 대신 재생성에 필요한 절차와 데이터 명세를 제출할 수 있는지 공고에서 확인하세요.

## 주요 하위 경로

- `org/`: 원본 회의록 JSON
- `to_text/`: 발언 단위 텍스트와 메타데이터
- `metadata_jsonl_python/`: 발언 메타데이터/요약 JSONL
- `org_jsonl/`: 메타데이터와 발언 원문을 결합한 JSONL
- `chroma_db/`: 벡터 검색 인덱스
- `bm25_index/`: FTS5 BM25 인덱스
- `source_metadata.sqlite3`: 원문 행 위치·메타데이터 SQLite 인덱스
- `answer_cache.sqlite3`: 앱의 분석 결과 캐시

전체 역할과 재생성 명령은 프로젝트 루트 `README.md`를 확인하세요. 원문 데이터를 불필요하게 복사하거나 공개하지 마세요.
