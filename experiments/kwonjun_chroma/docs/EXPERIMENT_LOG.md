## 9. 실패·대안 및 판단

- enriched 입력은 성능 저하와 LLM metadata의 의미 과대표현 가능성으로 제외
- KURE는 비교 표본에서 Arctic보다 낮아 전체 재임베딩하지 않음
- Chroma는 대규모 metadata 필터가 느려 서비스 DB에서 제외
- 외부 상용 LLM API는 데이터 외부 전송 조건 때문에 사용하지 않음
- 단일 이슈 소표본에 복잡한 딥러닝 예측을 적용하지 않음
- 지도 연결선은 인과적 전파가 아니라 시간적 관측 순서로 제한해 표현

## 10. 최종 선택 이유

최종 구성은 최고 복잡도가 아니라 검색 정확도, 필터 성능, 재현성, 오프라인 실행,
근거 추적 가능성과 제출 일정 내 검증 가능성을 함께 고려해 선택했다.
