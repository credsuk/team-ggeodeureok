# 2026-10-20 작업 기록

## 오늘 목표

1. 검수 라벨로 임베딩·하이브리드 검색 성능 비교
2. 최종 검색기를 Chroma에 적재하고 FAISS와 결과 일치 검증
3. 검색 결과를 검수 이슈·전파 타임라인·예측에 연결
4. 데모 화면과 GitHub 공유 구조 정리

## 완료한 작업

### 1. 검색기 벤치마크

- 비교: Arctic, KURE, Dense RRF, BM25, Hybrid RRF, Hybrid rerank
- 동일한 dev 라벨과 `top-k` 조건으로 nDCG, Recall, MRR 계산
- Arctic가 nDCG@5 0.9908, MRR 1.0으로 가장 높아 최종 채택
- 하이브리드와 reranker는 성능 향상이 없어 현재 버전에서 제외

### 2. Chroma 구축과 검증

- 컬렉션: `council_policy_arctic_v1`
- 적재: 정책 의미 청크 25,340개
- 저장 항목: `chunk_id`, 본문, 의회, 위원회, 회의일자, 회의록명, 안건, 발화자,
  근거 참조, `embedding_row`
- 원본 임베딩과 Chroma 저장 벡터의 최대 오차: `0.00000001`
- 동일 질의 비교: FAISS/Chroma `overlap@10=1.000`, Top-1 일치

### 3. 통합 검색

```text
사용자 질의
  → Arctic query embedding
  → Chroma 정책 청크 후보 50개
  → cluster assignment 결합
  → 군집 유사도·검색 순위로 이슈 점수 계산
  → 사람 검수 완료 issue_id만 통과
  → 최초 관측·전파·월별 변화·예측 결합
```

검색어와 직접 연결된 대표 근거와 최초 관측 근거는 목적이 다르므로 결과 JSON과 UI에서
별도로 표시하도록 확정했다.

### 4. 안건 메타데이터 보강

- 재임베딩 없이 기존 Chroma 메타데이터만 갱신
- `agenda_title_raw`: 원본 안건 문자열
- `agenda_title_effective`: 정제·보강한 표시용 안건
- `agenda_confidence`: 보강 신뢰도
- `agenda_reason`: 선택 근거
- `evidence_title`: UI용 최종 제목

### 5. 데모 UI v2

- 긴 단일 페이지를 `전파 지도 / 시계열·예측 / 근거 원문` 탭으로 분리
- 기술 경로 설정은 접힌 고급 설정으로 이동
- 단순 외곽선 대신 오프라인 대한민국 행정 경계 지도 사용
- 긴 지역 라벨 대신 번호 마커를 표시하고 hover에서 날짜·시차·근거 수 제공
- 주황색 1번은 최초 관측, 파란 번호는 후속 관측으로 시각적 역할 구분
- 실제 정책 인과 전파가 아니라 데이터 내 시간 순서임을 화면에 명시

## 오늘 발견한 문제와 수정

| 문제 | 수정 |
|---|---|
| SentenceTransformer 3.4.1로 만든 모델을 3.3.1에서 읽는 경고 | `requirements.txt`를 3.4.1로 고정 |
| 기술 설정과 결과가 한 화면에 섞여 복잡함 | 설정을 sidebar 고급 영역으로 접고 결과를 탭으로 분리 |
| 지도 라벨이 겹쳐 순서를 읽기 어려움 | 실제 지도 배경 + 번호 마커 + 전파 순서표 |
| 검색 대표 문장이 최초 관측처럼 보임 | 검색 대표 근거와 최초 관측 근거 설명·영역 분리 |
| 팀 저장소 기존 코드와 파일명이 겹칠 가능성 | `experiments/kwonjun_chroma/` 독립 폴더로 패키징 |
