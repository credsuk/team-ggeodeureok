# 데모 영상 촬영 가이드

권장 길이는 4분 내외다. 설치 화면을 길게 보여 주기보다 입력, 계산 결과,
원문 근거, 재현성을 한 흐름으로 보여 준다.

| 시간 | 화면 | 발표 내용 |
|---|---|---|
| 0:00~0:20 | 제목·문제 정의 | 흩어진 지방의회 회의록에서 이슈 최초 관측·후속 논의·예측을 제공한다고 소개 |
| 0:20~0:45 | 파이프라인 그림 | 정제→청킹→임베딩→하이브리드 검색→군집→타임라인→예측 설명 |
| 0:45~1:40 | 대표 이슈 지도 | 최초 관측 의회, 시간순 후속 관측, 월별 변화 표시 |
| 1:40~2:30 | 자유 검색 | `출산율 저하 대응 정책` 입력 후 회의록명·일자·안건·원문 근거 확인 |
| 2:30~3:10 | 예측 | 지속 여부, 예상 언급량, F1·MAE·RMSE·방향성 정확도 설명 |
| 3:10~3:40 | 로컬 Agent | 근거를 묻고 Qwen이 검색 결과를 설명하는 장면 |
| 3:40~4:00 | 재현성 | README, Docker, 로컬 모델, 외부 전송 없음 안내 |

촬영 전 다음을 준비한다.

```bash
docker compose up -d pgvector
ollama list
bash scripts/run_final_app.sh
```

영상에서 API 키, `.env`, DB 비밀번호, 개인 경로를 노출하지 않는다. 외부
공공데이터 확장 화면은 공식 분석 결과와 혼동될 수 있으므로 기본 데모에서는
끄고 촬영한다.
