# Chroma 통합 지도·타임라인 데모

## 실행

```bash
cd ~/projects/council-minutes
source .venv/bin/activate
pip install -r requirements.txt
bash scripts/run_demo.sh
```

브라우저에서 `http://127.0.0.1:8501`을 엽니다. WSL Ubuntu에서 실행해도 Windows
브라우저의 같은 주소로 접속할 수 있습니다.

## 화면 구조

1. 정책 이슈 검색창
2. 선택 이슈와 최초 관측·관측 의회·근거 수 요약
3. `전파 지도` 탭
   - 대한민국 지도 위 번호형 관측 순서
   - 주황색 1번: 제공 데이터 내 최초 관측
   - 파란 번호: 의회별 최초 후속 관측
   - 전파 순서표: 날짜·시차·근거 수
4. `시계열·예측` 탭
   - 월별 근거 발언 수
   - 다음 달 언급량·증가·신규 의회 확산 보조 예측
5. `근거 원문` 탭
   - 검색어와 직접 연결된 대표 근거
   - 최초 관측과 의회별 후속 관측의 회의록·일자·안건·원문 구간

기술 경로와 장치 설정은 왼쪽 sidebar의 `고급 경로·모델 설정`에 접어 두었다.

## 대표 근거와 최초 관측의 차이

- **검색 대표 근거**: 사용자의 검색어와 의미적으로 가장 가까운 문장
- **최초 관측 근거**: 선택된 이슈가 제공 데이터에서 가장 먼저 나타난 문장

두 문장이 다른 의회·날짜에서 나오는 것은 정상이다. 화면에서는 검색 근거와 최초 관측
근거를 별도 영역으로 표시한다.

## 성능과 캐시

Streamlit은 다음 객체를 프로세스 메모리에 캐시한다.

- Arctic 질의 임베딩 모델
- Chroma 컬렉션
- 군집 배정 lookup
- 타임라인과 예측 JSON
- 오프라인 대한민국 지도 이미지

첫 검색은 모델과 HNSW 인덱스 로딩 때문에 느릴 수 있다. 같은 서버의 두 번째 검색부터는
초기화 비용이 반복되지 않는다.

## 해석 주의

- 지도 선은 실제 정책 전달의 인과관계를 입증하지 않는다.
- 제공된 회의록 안에서 같은 이슈가 처음 관측된 시간 순서를 시각화한다.
- 지도 좌표는 시각화에만 쓰며 모델 입력으로 사용하지 않는다.
- 예측은 분석 기준일까지의 내부 관측만 사용하고 낮은 신뢰도는 명시한다.
