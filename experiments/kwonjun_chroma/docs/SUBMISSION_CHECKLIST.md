# 최종 제출 체크리스트

## 코드·문서

- [ ] 전체 소스와 전처리 코드가 포함되어 있다.
- [ ] `README.md`에 빠른 실행·전체 재구축·DB 복원 방법이 있다.
- [ ] `docs/PREPROCESSING.md`에 입력 스키마와 전처리 전후 건수가 있다.
- [ ] `docs/AI_USAGE.md`에 로컬 LLM 활용·검수·실패 사례가 있다.
- [ ] 예시 입력·출력과 실행 Notebook이 포함되어 있다.
- [ ] 환경 스냅샷을 생성해 라이브러리 실제 버전을 기록했다.

## 결과·평가

- [ ] 이슈명·최초 관측일·의회별 후속 순서·향후 예측이 표시된다.
- [ ] 회의록명·회의일자·안건·원문 구간이 근거로 표시된다.
- [ ] 검색 모델 비교와 최종 선정 이유가 기록되어 있다.
- [ ] 예측 F1·MAE·RMSE·방향성 정확도·rolling backtest가 기록되어 있다.
- [ ] 지도 연결선이 인과관계가 아닌 관측 시간순임을 명시했다.

## 보안·규정

- [ ] `.env`, API 키, DB 비밀번호가 없다.
- [ ] 원본 회의록과 원문 포함 산출물을 공개 Git에 올리지 않았다.
- [ ] 상용 외부 LLM API로 회의록을 전송하지 않았다.
- [ ] 공식 분석·예측에 2025-12-31 이후 자료를 사용하지 않았다.
- [ ] `COUNCIL_ENABLE_EXTERNAL_REFERENCE=0`으로 공식 데모를 실행한다.

## 실행 검증

- [ ] `python -m compileall -q src agent demo scripts`가 통과한다.
- [ ] 모든 `scripts/*.sh`가 `bash -n`을 통과한다.
- [ ] DB dump SHA-256이 공유 파일과 일치한다.
- [ ] 새 폴더에서 DB 복원 후 웹이 실행된다.
- [ ] 인터넷을 끈 상태에서 핵심 검색·예측·Agent가 실행된다.
- [ ] 3~5분 데모 영상이 재생된다.
