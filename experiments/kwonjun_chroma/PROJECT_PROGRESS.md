기준일: 2026-10-20  
분석 범위: 주최 측 제공 2024–2025년 광역 지방의회 회의록  
보안 원칙: 회의록 외부 전송 금지, 모델 다운로드 후 전 과정 로컬 실행

## 2. 확정 아키텍처

```text
JSON/HTML 정제
  → 부모 청킹
  → 정책 후보 필터
  → 의미 자식 청킹
  → Arctic 임베딩
  ├─ FAISS IndexFlatIP: 정확 검색 기준선·모델 비교
  └─ Chroma: 영속 검색·메타데이터 필터·데모
  → KMeans 군집화
  → Qwen3 로컬 LLM 이슈명 제안
  → 사람 검수 및 issue_id 고정
  → 최초 관측·의회별 후속 관측·월별 변화
  → 시간순 검증 예측
  → Streamlit 지도·타임라인·원문 근거
```

FAISS와 Chroma는 경쟁 관계가 아니라 역할을 분리한다. FAISS는 정확 검색 기준선,
Chroma는 데모와 메타데이터 필터를 담당한다.

## 3. 오늘 확정한 검색 성능

| 구성 | nDCG@5 | Recall@5 | MRR |
|---|---:|---:|---:|
| Arctic | **0.9908** | **0.2851** | **1.0000** |
| Dense RRF | 0.9899 | 0.2851 | 1.0000 |
| KURE | 0.9813 | 0.2841 | 1.0000 |
| Hybrid RRF | 0.9684 | 0.2803 | 1.0000 |
| Hybrid rerank | 0.9642 | 0.2813 | 0.9896 |
| BM25 | 0.8568 | 0.2675 | 0.9896 |

결론: 복잡한 하이브리드 구성이 검수 세트에서 이득을 주지 않아 Arctic 단일 검색을 채택했다.
Chroma와 FAISS의 동일 질의 비교는 `overlap@10=1.000`, Top-1 일치였다.

## 4. 데이터 보존 구조

| 파일·저장소 | 내용 | 공개 여부 |
|---|---|---:|
| `documents.parquet` | 회의록 단위 정제 원문 | 금지 |
| `chunks.parquet` | 부모 청크와 원문 위치 | 금지 |
| 정책 의미 청크 | 검색·군집화용 자식 청크 | 금지 |
| FAISS/NPY | 정확 검색 기준 벡터 | 금지 |
| Chroma | 검색용 벡터·메타데이터 | 금지 |
| `src/`, `demo/`, `scripts/` | 코드 | 가능 |
| `examples/` | 직접 만든 합성 예시 | 가능 |

원문은 요약 CSV로 대체하거나 삭제하지 않는다. 정제 원문과 각 청크의 문자 범위를 보존해
모든 결과가 회의록명·일자·원문 구간으로 돌아갈 수 있게 한다.

## 5. 주요 오류와 수정

| 문제 | 원인 | 수정 |
|---|---|---|
| UTF-8 파일 인코딩 오판 | 앞부분의 일부 비정상 바이트 | JSON 구조 확인 후 UTF-8 대체 디코딩·스트리밍 |
| 전체 청크 군집 잡음 | 진행 발언·인사·명단 포함 | 정책 후보와 의미 자식 청크 별도 생성 |
| 정책 후보 0건 | 필터와 실제 컬럼 불일치 | 제외 사유별 카운트·샘플 출력 후 조건 보정 |
| 긴 청크 주제 혼합 | 한 벡터에 여러 정책 포함 | 부모 보존 + 600자 목표 의미 자식 청킹 |
| K=100 이슈가 넓음 | 군집당 문서가 과다 | K=160 채택 |
| LLM이 모든 군집을 정상 판정 | 대표 발언 일부만 보고 과잉 일반화 | 지지 근거·이상치 출력, 75% 품질 게이트 |
| SentenceTransformer 버전 경고 | 생성 3.4.1, 실행 3.3.1 | `sentence-transformers==3.4.1` 고정 |
| 검색 대표 근거와 최초 관측 혼동 | UI에서 근거 역할이 섞임 | 검색 근거와 최초 관측 근거를 별도 탭·설명으로 분리 |
| 기존 지도 라벨 겹침 | 지점마다 긴 텍스트 표시 | 실제 대한민국 지도 + 번호 마커 + hover 상세로 교체 |

## 6. 결과 해석 원칙

- 최초 관측은 전국 최초가 아니라 제공 데이터 범위 내 최초 관측이다.
- 전파는 의회별 최초 관측의 시간 순서이며 인과관계를 단정하지 않는다.
- 같은 날짜의 여러 의회는 공동 최초로 처리할 수 있다.
- 같은 부모 청크에서 나온 여러 자식 청크는 관측량 계산 시 중복 제거한다.
- 검색 대표 근거는 질의와 가장 유사한 문장이고, 최초 관측 근거는 날짜 계산의 근거다.
- 2025-12-31 이후 외부 정보는 분석·예측에 사용하지 않는다.
