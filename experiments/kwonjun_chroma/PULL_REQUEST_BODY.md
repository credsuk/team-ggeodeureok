## 변경 내용

- 정책 의미 청크용 Arctic 임베딩 검색 파이프라인 추가
- FAISS 정확 검색과 Chroma 영속 검색 역할 분리
- 임베딩·BM25·RRF·reranker 동일 조건 벤치마크 코드 추가
- Chroma 검색 결과를 검수 이슈, 최초 관측, 후속 관측, 예측과 연결
- 안건 표시용 메타데이터 보강 로직 추가
- 대한민국 지도 기반 Streamlit 데모 v2 추가
