# notebooks/ — 재현 가능한 분석 노트북

현재 이 폴더에는 Jupyter Notebook이 없습니다. 프로젝트의 데이터 처리·검색·앱 동작은 `scripts/`와 `src/`의 Python 코드로 수행합니다.

## 제출 전에 할 일

- 노트북이 제출 요건이라면 실제 실행한 분석·평가만 `.ipynb`로 추가하세요. 완료되지 않은 실험을 결과처럼 작성하지 마세요.
- 노트북에 목적, 입력 데이터와 버전, 실행 순서, 출력 해석, 한계를 적으세요.
- 절대 경로, 개인 정보, API 키·비밀번호를 제거하고 프로젝트 상대 경로를 사용하세요.
- 가능하면 깨끗한 환경에서 처음부터 재실행해 모든 셀이 실행되는지 확인하세요.
- 전체 원문이나 대용량 결과를 노트북 출력에 포함하지 말고, 데이터 이용 조건에 맞춰 최소한의 예시만 사용하세요.

정량 검색 평가를 수행한다면 관련 발언 ID가 표시된 평가 질문 세트, 지표 계산 코드, 실제 결과를 함께 기록하세요. 해당 평가는 현재 수행된 것으로 확인되지 않았습니다.
