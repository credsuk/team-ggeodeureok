# demo/ — 테스트·추론 시연 영상

현재 이 폴더에는 데모 영상이 없습니다. 앱의 핵심 기능을 실제 실행해 녹화한 영상이 준비되면 여기에 추가하세요.

## 권장 시연 순서

1. 앱 제목과 분석하려는 정책 쟁점을 소개합니다.
2. 질문을 입력하고 진행 상태를 보여줍니다.
3. 답변의 핵심 사실·회의 날짜·의회·안건·출처 ID를 확인합니다.
4. 원문 근거, 날짜순 논의 흐름, 의회별 지도·표를 열어 결과와 연결을 보여줍니다.
5. 결과가 검색된 후보 범위에 한정되고 전망이 확정 예측이 아니라는 점을 짧게 설명합니다.

## 녹화 전에 확인할 것

- Ollama 모델과 가중치, ChromaDB·BM25 인덱스, TXT 원문 및 Python 패키지가 준비되어 있는지 확인합니다.
- 실제 데이터에 질문을 실행해 근거와 화면을 검토합니다. 모의 화면이나 합성 결과를 실측 결과처럼 제시하지 마세요.
- 개인 정보, 로컬 경로, 비밀값, 무단 공개 데이터가 화면에 나오지 않도록 합니다.
- 영상 길이·파일 형식·용량은 대회 제출 안내에 맞춥니다. 공식 요건을 확인하기 전에는 규격을 임의로 정하지 마세요.
